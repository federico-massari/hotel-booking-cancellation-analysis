# Dashboard

Interactive dashboard built in Tableau Public, covering seven of the eight patterns documented in the main README (length of stay is analyzed in SQL only).

**View live:** [Hotel Booking Cancellation Analysis](https://public.tableau.com/views/Project2-HotelBooking/HotelBookingCancellationAnalysis?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)

Exploratory SQL & Tableau cancellation analysis of 119,390 hotel bookings. Cancellation rate rises with lead time, from 9.63% (0-7 days) to 50.65% (90+ days).
